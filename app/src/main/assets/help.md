# Справка DPmetaApp

DPmetaApp — мобильная студия разработки: проекты на GitHub, IDE и ИИ на одном телефоне. Ссылки ниже ведут в разделы приложения и в его настройки; адреса сайтов — по двум касаниям: первое копирует, второе открывает.

## Разделы

Панель открывается кнопкой ≡ слева вверху.

- **Сводка** — числа по всем проектам: что работает, вопросы автору, PR, ошибки источников. [Открыть](app:summary)
- **Проекты** — список проектов, PR и вопросов; вкладки — в верхней панели. [Открыть](app:projects)
- **IDE** — файлы проекта, редактор, терминал Linux. [Открыть](app:ide)
- **AI** — сессии Claude, Codex и Gemini, задачи, запросы на подтверждение, модели. [Открыть](app:ai)
- **Настройки** — всё одним документом, с поиском: оформление, проекты, хранилище и секреты, управление ИИ, копии, журнал. [Открыть](app:settings)

## Первые шаги

1. Создайте токен GitHub — fine-grained, доступ на чтение содержимого, PR и метаданных: [страница токенов GitHub](https://github.com/settings/personal-access-tokens).
2. Вставьте его в настройках: [Настройки → токен](app:settings?q=токен). Токен хранится под ключом Keystore и открывается PIN или биометрией.
3. Нажмите «Обновить» на сводке — пульт прочитает проекты.
4. Отметьте репозитории в «Клоны…» — они появятся в `~/projects/<владелец>/<имя>`: их видят IDE, терминал и ИИ. [Настройки → клоны](app:settings?q=клоны)
5. Установите Linux в приложении и войдите в слот Claude — «AI» → «Настройки AI» → «Linux в приложении». [Настройки → AI](app:settings?q=linux)

## Проверка

«AI» → «Настройки AI» → «Проверка» показывает, что не так, почему и что делать; решение — кнопкой, где оно есть. Пока проблемы есть — полоса над вкладками «AI» и «проблем: N» в строке «AI» сводки. Там же — мастер настройки: Linux, Claude Code, вход, токен GitHub, автор коммитов.

Само, без нажатия, приложение делает только безопасное: чинит повреждённые пакеты Linux, пишет помощник входа GitHub для Git (токен он берёт из `GH_TOKEN`, только если вы включили «давать ИИ»), обновляет DNS Linux при смене сети и догоняет клоны без ваших правок и коммитов. Что сделано — списком «Исправлено само» и строкой в журнале. Права, секреты и данные меняются только вашим нажатием. [Открыть «AI»](app:ai)

## Хранилище

Одно хранилище для IDE, терминала и ИИ — домашняя папка Linux приложения:

- `~/projects` — проекты: клоны GitHub — `<владелец>/<имя>`, свои — `local/<имя>`;
- `~/tools` — инструменты: `bin` (он первым в `PATH`), службы IDE (`ide`), модели (`models`);
- `~/ai` — слоты ИИ, `<исполнитель>-<N>`; менеджеру файлов не виден.

Карта `~/STORAGE.md` обновляется сама после установки, загрузки и клона; ИИ узнаёт о ней из своей инструкции.

**Место.** «Предел хранилища, ГБ»: `0` — всё свободное место телефона. Загрузка, установка, новый клон и сборка в Linux приложения не начнутся, если после них на телефоне останется меньше 1 ГБ — это жёсткий запас. [Настройки → хранилище](app:settings?q=хранилище)

## IDE

- **Поиск** — кнопка в списке файлов: «Файлы» ищет по именам и путям, «Код» — по тексту или регулярному выражению, от открытой папки вниз; «Заменить все…» меняет найденное во всех файлах после окна с числами. Касание файла открывает вкладку, касание строки — вкладку на этой строке. Служебные папки (`.git`, `build`, `node_modules`) и файлы больше 1 МБ не просматриваются.
- **Артефакты и APK** — «Сборка», «Артефакты»: найденные файлы сборки; у APK — «Установить» (сначала окно с пакетом, версией, подписью и SHA-256, ставится показанная там копия; затем подтверждаете в окне Android), «Подписать» своим ключом из Keystore телефона, «В Загрузки». Дерево на ПК — «На телефон» скачивает файл по SFTP (на ПК ничего не меняется), дальше — «Установить», «Запустить».
- **История сборки** — внизу «Сборки» и «Проверок»: каждый запуск с исходом, временем, веткой и коммитом; касание раскрывает шаги, ошибки и вывод.
- **Файлы ПК** — у дерева на ПК «Файлы» открывают его по SFTP: просмотр, поиск и правка с сохранением обратно на ПК (файл изменили на ПК — приложение скажет о конфликте).
- **Запуск** — рабочий экран проекта, «Запуск»: команда и папка программы; «▶ Собрать и запустить» открывает её во вкладке терминала, только если сборка прошла. На Windows-ПК команда выполняется в PowerShell по SSH: одна строка до 1500 знаков, после неё — «[Код выхода: N]» и PowerShell в той же папке.
- **Сборка в несколько шагов** — рабочий экран проекта, «Сборка» и «Проверки»: шаги по порядку, следующий — после успешного; «Шаблон» подставляет CMake, Gradle, Make, CTest, Python.
- **Отладка** — C, C++ и Python в Linux: точка останова — касанием номера строки, «Отладка» над полем файла или на странице «Запуск» проекта; на остановке — строка подсвечена, внизу — шаги, стек, переменные и выражение. Нет отладчика — «Поставить gdb» или «Поставить debugpy». Дерево на ПК — «Отладка» на странице «Запуск»: отладчик работает на самом ПК (Linux — gdb 14+ и debugpy, Windows — только Python с debugpy); ставите его вы, приложение подскажет команду.
- **Logcat** — «Logcat» в списке файлов: журнал Android по беспроводной отладке телефона к самому себе — пакет, уровень, поиск, пауза; строка трассировки открывает файл на строке. У APK в «Артефактах» — «Запустить» и сразу его logcat. Права adb — права shell, ими пользуются и терминал, и ИИ.
- **ИИ-дополнение** — «ИИ: дописать» у файла проекта: модель дописывает код в месте курсора, ответ вставляется по «Вставить». Источник проекта — «Вид / команды» → «ИИ-дополнение…»: выключено (по умолчанию), локальная модель или облачная с согласием на отправку кода. Уходит только окно открытого файла, ключи вырезаются.
- **Предпросмотр Compose** — «Предпросмотр» у файла Kotlin с @Preview: функция открывается в самом приложении на телефоне (его debug-сборка с ui-tooling) через adb, снимок экрана — в панель. У разметки XML — «Показать разметку» из установленного APK (свои виды — рамками). Файл в дереве на ПК — ещё «Нарисовать на ПК»: Robolectric рисует функции и разметку в самом проекте на ПК (там нужны JDK и Android SDK), картинки — в панель.
- **Отладка своего APK** — «Отладка» у установленного APK (сборка debug) в «Артефактах»: приложение перезапустится и подождёт отладчика; точки — касанием номера строки в файлах .kt и .java, на остановке — стек, переменные, шаги. «Остановить» отключает отладчик, приложение работает дальше.
- **В ИИ** — над полем файла проекта: выделение (или строка курсора), замечания, символ, импорты и использования — в сессию задачи, новой задачей или во вкладку ИИ терминала; направление запоминается для проекта. У предела ИИ — предложение другого подключённого ИИ; автоматически — только если включено в «Контуре».
- **Ошибки сборки** — после ▶ в строке терминала «Ошибки: …», на рабочем экране — под выводом проверки и сборки. Касание строки открывает файл на месте ошибки.
- **Редактор** — «Править» у файла: подсветка, вкладки, поиск и замена в файле, отмена; файл меняет только «Сохранить».
- **Семантика** C++, Python и Kotlin включается кнопкой над полем редактора; языковая служба ставится тоже кнопкой, сама ничего не скачивает.

## Секреты

Все секреты приложения — одним списком, без значений. «Давать ИИ» можно токену GitHub, ключам API-профилей и токену Hugging Face; Admin-ключи, токены маршрутов и облачной копии — только в списке. [Настройки → секреты](app:settings?q=секреты)

- Выданное попадает в окружение Linux приложения — ходам ИИ и терминалу; на ПК-target не уходит и на диск не пишется.
- Ключ, который у слота перекрыл бы вход по подписке, слот видит под именем `DPMETA_<имя>` — например, `DPMETA_ANTHROPIC_API_KEY`: подписка не переключается на оплату по API.
- Токен GitHub для ИИ открывается входом раз за запуск и отзывается при остановке службы.
- **Свой секрет** — «Добавить свой секрет»: имя вроде `MY_SERVICE_TOKEN` станет переменной окружения. Имена приложения (`GH_TOKEN`, ключи провайдеров) и системные (`PATH`, `LD_…`) не принимаются.

Ключи: [Anthropic Console](https://console.anthropic.com/settings/keys), [Hugging Face](https://huggingface.co/settings/tokens).

## Оформление

Тема, акцент, размер текста, плотность и шрифт редактора — сразу во всём приложении. «Обои телефона» — цвета обоев на Android 12 и новее. [Настройки → оформление](app:settings?q=тема)

## Частые вопросы

**Загрузка или установка не начинается.** Не хватает места: после неё осталось бы меньше 1 ГБ или приложение вышло бы за предел. Освободите место или поднимите предел. [Настройки → место](app:settings?q=место)

**Терминал не находит программу, поставленную IDE.** Откройте новую вкладку терминала: `~/tools/bin` попадает в `PATH` при входе в оболочку.

**Где клоны, которые раньше были в `/root/repos`?** В `~/projects`; на старом месте — ссылка.

**Claude в слоте ведёт себя как при оплате по API.** Проверьте, что в слоте нет `ANTHROPIC_API_KEY`: приложение его не выдаёт, ключ доступен как `DPMETA_ANTHROPIC_API_KEY`.
