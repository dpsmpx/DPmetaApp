# Documentation consistency audit

Execute the task `docs/doc-audit/TASK.md` of this repository from start to
finish, as a fresh audit against the current state of every repository.

`docs/doc-audit/TASK.md` is the only procedure. It is the author's
"Cross-Repository Documentation Consistency Audit" brought in line with
M-04 by decision M-09 (`docs/DECISIONS.md`); its section 14 lists every
difference from the author's original wording and why. Do not follow any
other copy of the procedure.
