# Ветка сборок для Linux DPmetaApp (`linux_debug`)

Одна ветка сборок на платформу (`DPmetaApp:D-33`). Здесь только последние
сборки, без истории `main`: каждая сборка — коммит-сирота и
принудительный пуш. У каждой подсистемы свой каталог, его `README.md`
называет коммит `main`, из которого он собран.

| каталог | что | из `main` |
|---|---|---|
| `dppass/` | DPpass для ПК 0.1.20-dev: архив, `PKGBUILD`, `SHA256SUMS` | `08da814` |

Прежняя ветка `linux-debug` (сборки по версии) больше не нужна — её
удаляет автор на GitHub (`DPmetaApp:D-33`).
