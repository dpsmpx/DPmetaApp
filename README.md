# DPmetaApp

Мобильный пульт автора над экосистемой его репозиториев: девять
проектов (`DPmeta:docs/ECOSYSTEM.md`), ход разработки, сайт
`dpsmpx.com`, несколько аккаунтов Claude, статистика и графики — на
Android-телефоне. Приложение читает проекты, а не заменяет их: о проекте
прав его репозиторий, изменения идут через процессы проектов.

## Что где

| Вопрос | Документ |

| зачем каждое правило и откуда оно взято | [`docs/PROCESS.md`](docs/PROCESS.md) |

Нужна ли приложению официальная подпись разработчика — ТЗ, §12 (кратко:
для 1.0 — нет, нужен собственный ключ выпуска).

## Проверки

```sh
tools/check/run.sh                  # static: документы, процесс, секреты — секунды
tools/check/run.sh full             # и самотесты проверок; перед вливанием
tools/check/run.sh --write-status   # переписать блок состояния ниже из ROADMAP
```

Нужен только Python ≥ 3.11 и git. GitHub Actions не используются.
