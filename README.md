## DPpass с окном — установка на Garuda

```sh
git clone --depth 1 --branch linux-debug https://github.com/dpsmpx/DPmetaApp.git dppass-linux
cd dppass-linux
sha256sum -c SHA256SUMS
makepkg -si
```

`makepkg -si` поставит и зависимости: Java 17+ (`java-runtime`, например
`jre-openjdk`), `iproute2`, `polkit`, `util-linux` (последние три на Garuda
уже есть). Репозиторий приватный: `git clone` спросит вход в GitHub.

Запуск — «DPpass» в меню или `dppass` в терминале. Polkit спросит пароль
администратора: окну нужна одна возможность — настройка сети
(`CAP_NET_ADMIN`). Root у окна не остаётся: `dppass-launch` запускает его от
вашего пользователя только с этой возможностью (`setpriv`). Пароль
кешируется polkit на несколько минут.

## Как пользоваться

1. «Подписки» → «Добавить по адресу…» → адрес подписки `https://…` →
   серверы загрузятся и применятся. Ссылки `vless://…` и документ DPpass —
   меню «Импорт» → «Из буфера обмена» или «Из файла…».
2. «Серверы» — выбрать сервер двойным щелчком или оставить «Авто»;
   «Проверить задержку» — только когда туннель выключен.
3. «Подключение» → кнопка питания. Под ней — сервер, время и трафик;
   отказ — с причиной.
4. «Журнал» — события этого запуска без секретов; «Копировать журнал».

## Что делает с системой

- TUN `dppass0` — пока окно подключено; с выходом исчезает сам.
- Правила маршрутизации `ip rule` с приоритетами 7350–7353 и таблицы
  7350/7351: всё — в туннель; сокеты самого ядра (метка `0x7350`) — мимо;
  «локальная сеть напрямую» — мимо; DNS на порт 53 любого адреса, в том
  числе роутера, — в туннель, его отвечает ядро DPpass. Резолвер системы и
  NetworkManager не перенастраиваются.
- Отключение и закрытие окна убирают правила; после аварийного выхода их
  уберёт следующий запуск.
- Данные — `~/.local/share/dppass` (только для вас, права 0700).

Удалить: `sudo pacman -R dppass-desktop`, данные — `rm -r ~/.local/share/dppass`.

## Интернет через телефон с DPpass

DPpass для Linux через телефон пока не подключается. Как пустить ПК через
туннель DPpass на Android с раздачей — весь ПК или только браузер — см.
[`VIA_PHONE.md`](VIA_PHONE.md).

## Чего в первой версии нет

Раздачи, устройства раздачи, режима без сервера, проверки сети,
наблюдателя сеанса со сменой сервера, автообновления подписок, реакции на
смену сети (`DPpass:D-74`, этап 6). Выбор приложений туннеля на Linux не
выражается: конфигурация с ним отказывает с причиной.

## Как собрано

Код — коммит `1e6434f` рабочей ветки `ccr-c0380b37-vo299h` (PR #67, влит в `main` 21 октября 2026),
PKGBUILD — по шаблону коммита `041f0d6`. Облачная сессия 21 октября 2026:
OpenJDK 21, Gradle 9.8.0, Go из `tools/xray/go.mod`, ядро Xray 26.9.30.
Google Maven (`dl.google.com`) закрыт сетевой политикой окружения, поэтому
сборка шла во временной копии `dppass/` без плагина Android (Android Lint не
запускался), а Maven Central — через локальное зеркало с повторами при 429;
проверка зависимостей Gradle (`verify-metadata`) включена.
