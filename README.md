## Подпись — отладочный ключ облачной сессии, не ключ автора

`CN=Android Debug`, SHA-256 сертификата
`a6f95acb9a77aa74a58ee809860b482f4dd0ea2a1625706fb87bf99577a1ef30`.

Ключ **другой**, чем у прежней сборки `apk-0.1.0-dev.1`
(`60551def…fa78`) и у сборок, сделанных на самом телефоне. Поверх
приложения с другой подписью Android эту сборку не поставит: старое
придётся удалить, а с ним — настройки и ключ приложения в Keystore.
Поэтому до удаления:

1. Targets → «Копия настроек» → «Сохранить сейчас»: копия уходит в
   «Загрузки/dpai-backup» и в Termux, `~/.dpai/app-settings.json` (D-51,
   D-54).
2. Удалить прежнее приложение, поставить этот APK.
3. В новом приложении — карточка «Восстановление после переустановки»:
   команда для Termux заменит прежний ключ приложения в
   `authorized_keys`, после чего приложение само возьмёт настройки из
   копии в Termux и заведёт targets слотов (D-54). Ключ приложения на
   ПК без связки proot — по «Инструкция» → «10. ПК с Windows».

Сборка отладочная: Compose в ней заметно медленнее, чем в release.
Release подписывает только автор своим ключом (ТЗ DPmetaApp, §12.4;
свойства `dpai.release.*` — `dpai/docs/PROCESS.md`, §6).

## Как скачать

Репозиторий приватный: ссылки `raw` без входа отвечают 404. На ПК —
`git clone --depth 1 --branch apk-0.1.0-dev.1-2026-10-11

котором вы вошли в GitHub. Сверить сумму: `sha256sum -c SHA256SUMS`.
