# Сообщение JVM о PaX: что оно доказывает

22 ноября 2026. Основание — журнал API-модели автора в Android/Alpine:
пакет OpenJDK установлен, но JVM останавливается с сообщением
`Failed to mark memory page as executable`.

Проверен официальный [OpenJDK 21u, os_linux.cpp, check_pax](https://github.com/openjdk/jdk21u/blob/master/src/hotspot/os/linux/os_linux.cpp).
Функция выделяет анонимную страницу RW через mmap, затем запрашивает
RWX через mprotect. При возврате -1 выдаёт это сообщение независимо от
конкретного errno. Она не обнаруживает установленный PaX/grsecurity.
В сборке Zero проверка отключена; обычные флаги JIT не заменяют её.

Следствие D-216: состояние пакета и запуск JVM проверяются отдельно.
Смена ядра или paxctl не являются доказанным исправлением по одному
сообщению. Пробы java_debug и memory дают errno и размер страниц.
Причина на устройстве автора пока не установлена; хостовая проба не
является воспроизведением Android SELinux.

Код OpenJDK в приложение не переносился. Использован факт о смысле
диагностики и общеупотребимые POSIX-вызовы независимой пробы.
