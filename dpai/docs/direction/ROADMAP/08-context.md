# Этап 8 — Контекст и handoff

Состояние: выполнен (6 октября 2026).

## Цель

Структурированный версионированный контекст и handoff, с которыми
задача переходит между сессиями без потери смысла
(`docs/CONTEXT_MODEL.md`; ТЗ, §23–§28, §131).

## Объём

- `ContextBundle`, манифест источников, версия и хеш (D-10).
- Отбор по уровням: глобальный → проект → репозиторий → задача →
  документы → код и diff → прошлый handoff (ТЗ, §25).
- Сжатие с сохранением исходника (ТЗ, §26); handoff (ТЗ, §27).
- Границы секретности `PUBLIC` … `SECRET`, секреты исключены по
  умолчанию (ТЗ, §65); содержимое репозитория — недоверенный вход
  (ТЗ, §64).

## Критерии выхода

- [x] Задача переходит между сессиями с сохранением смысла контекста
      (ТЗ, §139, Phase 8): `ContextTest`, `taskMovesBetweenSessionsKeepingMeaning`.
- [x] Изменённый контекст — новая версия, а не тихое обновление:
      `ContextTest`.
- [x] Контекст проекта A не попадает в задачу проекта B (ТЗ, §67, §107):
      `ContextTest`, `otherProjectNeverLeaksIn`.
