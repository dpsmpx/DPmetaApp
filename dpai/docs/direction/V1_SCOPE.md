# Объём V1

Что входит в V1 и что — нет (D-20; ТЗ, §143). Работа вне этого списка
не начинается без нового решения и не мешает закрытию V1.

## 1. Сценарии V1

V1 обязана поддерживать пять сценариев ТЗ, §144. Каждый проверяется
сквозным тестом на `MockRunner` (этап 14) и на настоящем target (этап 19).

| № | Сценарий | Путь | Этапы |
|---|---|---|---|
| 1 | Параллельная разработка | 10 задач → 10 сессий в изолированных worktree → наблюдение | 3–9, 11 |
| 2 | Автоматическое продолжение | предел сессии → handoff → следующий подходящий аккаунт → продолжение той же задачи | 5, 6, 8, 14 |
| 3 | Восстановление после отказа | падение сессии → обнаружение → сверка → повтор или переназначение | 6, 13 |
| 4 | Завершение задачи | реализация → проверка → коммит → `DONE` | 9, 10, 14 |
| 5 | Глобальный прогон экосистемы | состояние экосистемы → следующая допустимая задача → исполнение → проверка → следующая | 15, 16 |

В сценарии 2 «следующий аккаунт» — в основном режиме одной подписки
свободный слот той же подписки или ожидание сброса предела; другая
подписка — только заведённая автором и с разрешённым переходом
(`rotationAllowed`, D-30). Оркестратор пределы не обходит (D-27); риски
нескольких подписок одного человека — `docs/ACCOUNT_MODEL.md`, §6.

## 2. Подсистемы V1

Все подсистемы ТЗ, §140 в объёме их Definition of Done (ТЗ, §126–§138):
ядро, хранение, execution targets (local/Termux, SSH, mock), Claude
Runner (CLI; SDK — по решению этапа 4), аккаунты, сессии, планировщик и
DAG, контекст и handoff, Git и изоляция worktree, проверка, мониторинг,
уведомления, восстановление, безопасность, Android-оболочка,
документация.

Приложение — среда полного контроля процесса, а не только наблюдения
(D-42): задачи, сессии, проверка, слоты и targets управляются с экрана и
командой `dpai`.

## 3. После V1 — полная версия (D-97)

Пункты, которые ТЗ отнесло к FUTURE, по слову автора входят в полную
версию подсистемы (D-97, `DPmetaApp:D-52`). Закрытию V1 они не мешают:
V1 замораживается по своим критериям (этап 20), части полной версии идут
после неё по порядку D-97, каждая — своим решением.
