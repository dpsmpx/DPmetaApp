## 8 ноября 2026 — сессия терминала в tmux (D-111)

- Вкладка терминала на POSIX target держит сессию в `tmux new -A -s
  <имя>`: после обрыва связи или перезапуска приложения — та же сессия.
  Настройка target «Держать сессию в tmux» — по умолчанию включена; нет
  `tmux` на target — строка, как поставить, и прежняя команда.
  Оболочка и сессия в tmux переподключаются сами, когда возвращается
  сеть («переподключаюсь…»); CLI слота — только входом в живую сессию,
  заново сам не запускается (без tmux — по кнопке). Закрытие вкладки
  завершает её сессию (точное имя; без сети — когда сеть вернётся). Имя
  сессии — с меткой устройства; target «в приложении» — свой сервер tmux
  на вкладку. tmux проработал и кончился с ошибкой (`kill-server`) —
  вкладка закрывается, программа заново не запускается; незавершённые без
  сети сессии помнятся и после перезапуска приложения. Формат
  `dpai.app-targets` v5 (`tmux`, пишется только `false`).
