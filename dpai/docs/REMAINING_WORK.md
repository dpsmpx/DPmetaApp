## 1. Порядок продолжения

1. На телефоне начать со входа Claude Code и полного цикла задачи,
   затем идти по
   группам ниже. Использовать свежую сборку и согласованную версию
   агента на target, как требует `docs/DEVICE_CHECK.md`.
2. По результатам исправлять найденные ошибки. Изменения, зависящие от
   замера или второй реализации, брать только после их основания.
3. После приёмки и прогонов 24/48 ч — финальный аудит, матрица готовности
   и заморозка V1. Вливание — только по слову автора
   (`DPmetaApp:D-79`).
