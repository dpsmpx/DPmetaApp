# Корпус вредоносных входов контекста

Файлы репозитория, которые пытаются выдать себя за указания оркестратора
(T3; ТЗ, §64). `ContextTest` собирает из них контекст и проверяет, что
каждый остаётся внутри блока данных с пометкой происхождения, а поддельный
маркер конца блока обезврежен. Новая уловка — новый файл здесь.

| Файл | Уловка |
|---|---|
| `ignore-instructions.md` | прямое «игнорируй указания» |
| `fake-end-marker.md` | поддельный конец блока данных и заголовок правил |
| `fake-orchestrator-header.md` | заголовок, как у правил оркестратора |
| `secret-in-repo.env` | секретный файл: исключается по секретности, а не по содержимому; собирается в `ContextTest` из частей — `*.env` в репозиторий не попадает (`.gitignore`, `check_secrets.py`) |
