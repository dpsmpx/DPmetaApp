# Корпус вывода `gh`

Образцы `gh pr list --json` и `gh pr view --json` для разбора
`connectors.GitHubCommands` (D-108). **Построены** 9 ноября 2026 по полям,
которые запрашивает приложение (`LIST_FIELDS`, `VIEW_FIELDS`), и по форме
ответа `gh` 2.97 (`statusCheckRollup` с `CheckRun` и `StatusContext`,
`author` объектом); логины, адреса и тексты — выдуманные. Записанный
вывод настоящего `gh` с телефона ляжет рядом
(`docs/DEVICE_CHECK.md`, §24).

| Файл | Что |
|---|---|
| `pr-list.json` | два PR: с пройденной и идущей проверками; черновик бота с упавшей и идущей проверками, пустым `reviewDecision` и знаками смены направления и управляющими в заголовке |
| `pr-view.json` | карточка PR: описание, `mergeable`, комментарий и одобряющий отзыв без текста |
