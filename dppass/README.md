# DPpass для ПК 0.1.20-dev — комплект для Windows x64

Собран из `main` DPmetaApp `08da814088f7ebcee5c9e8550cdee38d4fe28324`
(31 октября 2026): `python3 tools/desktop/windows_package.py` — архив и
`SHA256SUMS`. Сборка воспроизводится: тот же коммит даёт ту же сумму.
Оболочка — `dppass/docs/direction/DECISIONS.md`, D-97 (Windows) и D-74;
ядро Xray — в процессе, туннель — адаптер Wintun, который создаёт ядро.

Внутри: `dppass.exe` (запускатель), `runtime\` (Java — Eclipse Temurin
21.0.13, с `wintun.dll` 0.14.1), `lib\`, `native\dppassxray.dll`,
`geodata\`, `LICENSE`, `NOTICES.txt`.

Установка:

1. Сверить сумму в PowerShell:
   `Get-FileHash .\dppass-windows-0.1.20-dev.zip -Algorithm SHA256` —
   то же, что в `SHA256SUMS`.
2. «Свойства» архива → «Разблокировать» (иначе у каждого файла останется
   пометка «из интернета»).
3. Распаковать в `C:\Program Files\` — Windows спросит права
   администратора. Получится `C:\Program Files\dppass-windows-0.1.20-dev\`.

Запуск — `dppass.exe` из этого каталога: UAC спрашивает права
администратора (издатель — «неизвестный»: запускатель не подписан), с
ними работает всё приложение — без них адаптер Wintun не создать.
Запускатель сначала сверяет, что файлы комплекта может изменить только
администратор. Если распаковать архив, например, в «Загрузки», он
откажет с причиной — так и задумано (`dppass/docs/SECURITY_MODEL.md`,
T18). Данные — в `%LOCALAPPDATA%\DPpass`, ключ данных — под DPAPI
пользователя.

В облаке проверено в Wine: запускатель (права, окружение и командная
строка Java), самопроверка оболочки на этом рантайме (ядро 26.9.30,
DPAPI). Окно, UAC, адаптер, фильтры WFP и утечки DNS и IPv6 — только на
ПК: что проверить — `dppass/TODO.md`, «Windows — этап 7 (D-97)». Раздачи
и подключения через устройство раздачи на Windows пока нет. Сборки —
только для устройств автора (`DPmetaApp:D-24`), это не выпуск.
