# Рабочий экран проекта

Первый связанный экран этапа 4 — D-98, DP_AI_Orcestrator:D-132.
Открывается через «AI» → «Файлы» → «Рабочий проект».
Использует один проект, уже настроенный в Targets; новый реестр проектов
и дополнительные вкладки панели не создаёт.

Если задачи ещё нет, создайте её на вкладке «Задачи».
Выберите основное дерево или задачу контура. На экране видны target,
путь и назначенная ветка из настроек/реестра. Раздел «Изменения» отдельно обновляет фактическую ветку, HEAD, число
изменённых/новых файлов и конфликты. Несовпадение назначенной ветки видно;
ошибка обновления и усечение вывода не выдаются за чистое дерево. Задача без дерева
или с убранным деревом не переключает файлы на основной репозиторий.

- «Файлы»: домашняя папка in-app Linux и её подпапки, тот же редактор
  `docs/EDITOR.md`. Переходы между разделами сохраняют папку и открытый
  файл. При клавиатуре подробности сворачиваются. Скрытые пути и
  символьные ссылки не обходятся.
- «ИИ»: чат выбранной задачи и её прежний лист действий/истории.
- «Изменения»: фактический Git status/HEAD и diff задачи относительно ветки интеграции.
- «Проверки» и «Сборка»: отдельный ручной профиль CHECK/BUILD текущего
  проекта. Команда с аргументами и таймаут 1…86400 секунд; argv без
  неявного shell. Для скрипта укажите интерпретатор. Сохранение профиля
  отдельно от запуска; репозиторий сам команды не назначает.
  Проверки жизненного цикла ИИ остаются в листе задачи.

## Ручные профили

D-99, D-100, DP_AI_Orcestrator:D-133/D-134. Сначала сохраните или отмените
правки редактора выбранного дерева. Учитываются черновики того же файла
из обычной домашней папки Linux. Перед start контур проверяет отсутствие
незавершённых сессий, владельцев деревьев и очереди команд; весь проект
остаётся на паузе, включая запись редактора. После паузы заново читается
Git: несовпадение ветки, отсутствие HEAD или конфликты запрещают запуск.
Внешние терминалы/процессы не подчиняются замку приложения.

Вывод ограничен хвостом 65 536 позиций UTF-16 / 100 последних событий и проходит Redactor.
Итог показывает код выхода, остановку или таймаут. Он не завершает
ИИ-задачу и не заменяет её доказательство проверки. После ухода с экрана
работает общий worker со службой контроллера. Остановка службы через
уведомление не равна остановке удалённого процесса; якорь паузы остаётся.

После перезапуска start не повторяется: приложение сверяет уникальный
runId. LOST, отсутствие записи или ошибка SSH не освобождают проект.
«Безопасно остановить и снять паузу» подтверждает остановку агентом и
записывает постоянный запрет повторного старта ID. Пока агент недоступен,
остановка не подтверждена или остаются процессы, пауза сохраняется.
Старый агент без команд profiles/fence-stop требует обновления до старта.

Настройки и якорь — в приватном manual-profiles рядом с controller,
не внутри репозитория и не в облачной копии настроек. Смена проекта/target
и замена настроек заблокированы на время запуска; отложенная облачная
копия применяется при следующем запуске после снятия паузы. Секреты в argv не
добавляйте. Хранятся один профиль каждого вида на проект, один активный
запуск и последний результат; очередь сборок и история артефактов впереди.

Редактор занятого сессией дерева доступен только для чтения. Сохранение
заново проверяет проект, target, привязку task/worktree, путь, ветку и
owner. Сверка и локальная запись выполняются под замком контроллера:
его ход не захватит дерево между этими действиями. Занятый контроллер,
смена настроек или убранное дерево отменяют запись и сохраняют черновик.
Изменения внешних процессов защищены только сравнением исходных байтов
редактора; эти процессы не используют замок приложения.

«Черновики» показывает несохранённый текст из памяти, включая пустую
правку. Его можно просмотреть и скопировать, если исходное дерево уже
убрано. Запись в другое дерево автоматически не предлагается.
После смерти процесса черновики теряются; это не резервная копия.

Пока не входят в этот шаг: браузер удалённых файлов, выбор нескольких
рабочих проектов, многошаговые профили/run, артефакты, LSP. Меню дерева
показывает последние 200 неархивных задач; остальные — на доске.
Телефонная приёмка — в TODO.
