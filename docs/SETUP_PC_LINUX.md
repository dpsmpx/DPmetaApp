# Настройка: ПК с Linux как target (доступ с телефона из любого места)

Как для Windows (`docs/SETUP_PC_WINDOWS.md`), но ПК с Linux (D-70).
Основной сценарий — Claude на телефоне (D-50, D-53): вход и Claude Code —
в Termux на телефоне («Инструкция», разделы 1–7), файлы, проверки и Git
задачи — на ПК по SSH через частную сеть Tailscale; ПК в интернет не
открывается. **На ПК с Linux ещё не проверено** (17 октября 2026):
команда прогнана в песочнице (`PcSetupTest`), на настоящем ПК — нет.

## 1. Одна команда из приложения

1. Tailscale на ПК и на телефоне одним аккаунтом
   (<https://tailscale.com/download/linux>).
2. Targets → «Инструкция» → «11. ПК с Linux»: «Сохранить» архив агента и
   перенести `dpai-agent.zip` на ПК в «Загрузки».
3. «Копировать» команду, вставить в терминал ПК **от своего пользователя**
   (не root) в `bash` или `zsh` — в `fish` сначала наберите `bash`: `sudo`
   спросит пароль, где нужен root. Повторять безопасно. Нужен `sudo`
   (пользователь в группе `sudo` или `wheel`): без него команда скажет,
   что сделать под root.

Команда (текст — `ui/.../pc-setup.sh`) делает:

| Шаг | Что |
|---|---|
| 1 | пакеты через `apt-get`, `dnf` или `pacman` (в Arch — полным обновлением `-Syu`, Java 21 — по умолчанию через `archlinux-java`): `openssh-server`, `git`, `unzip`, Java 17 или новее (если нет) |
| 2 | SSH-сервер только по ключу: `/etc/ssh/sshd_config.d/10-dpai.conf` (вернуть пароли — удалить этот файл); основной `sshd_config` не меняется — если в нём нет строки `Include /etc/ssh/sshd_config.d/*.conf`, команда говорит, какие строки вписать вручную; ключи хоста (`ssh-keygen -A`) — на свежей системе их ещё нет; `sshd -t` перед перезапуском |
| 3 | ключ приложения в `~/.ssh/authorized_keys` с `from="100.64.0.0/10"` — только из сети Tailscale; прежний ключ DP AI заменяется, чужие ключи остаются |
| 4 | агент из `Загрузки/dpai-agent.zip` в `~/dpai`, обёртка `~/dpai-agent` с локалью `C.UTF-8` (`docs/EXECUTION_MODEL.md`, §5), `agent doctor` |
| 5 | поля для «Добавить»: адрес Tailscale, порт 22, пользователь, команда агента; отпечатки ключа хоста |

## 2. Target в приложении

Targets → «Добавить» по выведенным полям: «Команда агента dpai» —
`/home/<имя>/dpai-agent`, «Каталог Claude слота» — пусто, «Windows» — не
отмечать; «Получить ключ хоста» — **сверить с отпечатками** из вывода
команды (D-31); «Проверить». Затем у target — «Проект»: каталоги
репозитория и рабочих деревьев на ПК, «Где работает Claude» — Termux,
«Связать автоматически» (D-53: ключ связки — в `~/.ssh/authorized_keys`
пользователя, только из Tailscale), «Сохранить».

## 3. Если Claude должен работать на самом ПК

Target вида `LINUX_SSH` со своим входом (D-26): поставить Node.js и
Claude Code (`npm i -g @anthropic-ai/claude-code`), войти в Claude сразу в
каталоге слота (`CLAUDE_CONFIG_DIR=…`, D-29) и указать этот каталог в
«Каталог Claude слота». Вход и подписка — как у Termux-target
(`docs/ACCOUNT_MODEL.md`).
