# 0.4.0-dev.39 — разработка с API-моделями и автоматизации

Сборка для проверки автором из ветки `codex/automation-catalog`, PR #230,
поверх стека PR #222…#229. Публикация — в `apk_debug` по поручению
22 ноября 2026; слияние в main этим поручением не разрешено.
Точный коммит сборки, SHA-256 и сертификат подписи — в README/SHA256SUMS
каталога сборок и описании PR. APK остаётся отладочным.

## Изменения после опубликованной dev.38

- Быстрый старт API-разработки: существующий клон, ключ провайдера,
  выбор модели. Рабочее место создаётся автоматически, повторный старт
  не дублирует привязку. Проектный чат читает, ищет и меняет файлы,
  показывает изменения и позволяет отменить запись.
- Общий каталог четырёх источников автоматизации: команды пульта,
  ручные профили, уровни проверки задачи и окружение. CHECK/BUILD и
  диагностика доступны из IDE и API; остальные действия открывают
  прежние экраны с подтверждениями и терминалом. Устаревший профиль
  не запускается, результат и отмена относятся к собственному вызову.
- Межфайловое переименование с предпросмотром, проверкой внешних правок,
  отменой и восстановлением. Дополнение Kotlin применяет импорт вместе
  с основной правкой; исправлены индекс C++ и хранение кеша Kotlin.
- Анализ и закрепление зависимостей Gradle, pip и Conan 2 штатными
  инструментами выбранного проекта, подтверждение файлов и история.
- Общие уровни действий, уведомления и типы Git/GitHub. DPmeta, DPpass,
  DPvisualisation и контентная студия — самостоятельные проекты;
  отдельных APK этих проектов в этой сборке нет. Специальный target
  Termux удалён, обычные Linux приложения и SSH-targets сохранены.

## Где открыть

- «AI → Модели → Быстрый старт с ИИ» — выбрать клон, ключ и модель.
- Рабочий проект → «Автоматизации» — каталог, CHECK/BUILD и диагностика.
- Рабочий проект → редактор/изменения/зависимости — соответствующие
  инструменты IDE. Полный режим и дзен редактора сохранены.

Руководства: [быстрый старт](../AI_QUICK_START.md),
[автоматизации](../AUTOMATIONS.md). Само чтение каталога или открытие
проекта не начинает платный ход API.
