# DPmetaApp 0.4.0-dev.31 — тестовая сборка

Черновик описания для GitHub Releases. Публикация — только после PASS
нового full --strict; до этого release остаётся draft/prerelease.

## Что нового после dev.22

- Нативное поле редактора C++/Kotlin/Python: подсветка, номера строк,
  парные скобки, отступы, масштаб и перенос строк, вкладки файлов.
  Поиск/замена, undo/redo, комментарии, дублирование/перемещение строк,
  панель символов и аппаратные сочетания клавиш.
- Python: .py/.pyi/.pyw, обычные/raw/bytes/f-строки, вложенные выражения,
  Unicode-имена, декораторы, числа и Enter после заголовков с двоеточием.
- Приватные зашифрованные черновики с восстановлением текста/выделения
  после перезапуска. Исходники записываются явно; внешние изменения
  проверяются перед сохранением. Сохранение оставляет undo-историю.
- Рабочий экран проекта: файлы, ИИ, изменения, проверки и сборка;
  фактические Git status/HEAD, ручные CHECK/BUILD на свободном контуре.
  Несохранённые правки требуют сохранения/отмены, проект держится на паузе.
- DP-Verify: экран, фоновая проверенная двусторонняя синхронизация в простое,
  подключённый GitHub и доступ в памяти работающей службы после входа.
- Исправления устойчивости Markdown/JSON/Redactor и найденных аудитом
  ошибок; накопленные исправления других сессий сохранены в ветке.

## Где открыть редактор

**DPmetaApp → AI → крайний правый значок «Файлы» → папка → файл → «Править».**
Долгое нажатие на значок показывает название. До «Править» открыт обычный
просмотр файла без подсветки. Файлы телефона доступны через «Хранилище
телефона…» после предоставления доступа; папки Linux — из файлового браузера.
