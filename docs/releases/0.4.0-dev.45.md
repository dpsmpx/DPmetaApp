# 0.4.0-dev.45 — копирование диагностики

- Результаты сборки/проверок выделяются и копируются: отдельные кнопки
  для итога с выводом и для всего доступного текста вывода.
- Ошибки и важные сведения в истории запусков, установке SDK/пакетов,
  окружении, зависимостях, Git, APK/сертификатах, подключениях, моделях,
  файловых операциях и отладке получили общий способ копирования.
- Свёрнутые выводы и укороченный показ истории копируются без экранного
  усечения, в пределах сохранённого результата. В Logcat и выводе отладчика
  можно скопировать текущий показанный набор строк целиком.
- Копирование не меняет исходную ошибку и не раскрывает скрытые значения.
  Буфер обмена помечается чувствительным; Android 13+ подтверждает копирование
  сам, более старые версии получают короткое подтверждение.

Показанная на телефоне ошибка проверки SHA-256 дистрибутива Gradle
отслеживается отдельно в TODO. Проверка дистрибутива не отключена.
После установки нужно проверить копирование длинного результата на телефоне.
