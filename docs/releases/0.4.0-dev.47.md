# 0.4.0-dev.47 — единое оформление и простой рабочий экран

- Одни настройки оформления для пульта, IDE, редактора, терминала и окна
  запросов: системная, белая, тёмная и чёрная тема; фиксированный акцент или
  акцент из обоев. Нейтральный фон сохраняется, контраст акцента проверяется.
- Простой и полный вид используют те же данные и команды. В простом виде
  рабочий проект открывает код, чат и изменения; сборка, проверки, запуск,
  зависимости и автоматизации доступны рядом. Полный вид оставляет восемь
  прежних вкладок. Контекст, деревья, проекты и черновики доступны в шапке.
- Нет второй шапки рабочего проекта и ограничения ширины редактора 640 dp.
  Техническая форма профиля раскрывается отдельно, параметры разового
  запуска и кнопка запуска доступны сразу. Настройки документа, ключи
  подписи и команды кода сворачиваются без удаления возможностей.
- Терминал и запрос поверх приложений перекрашиваются без перезапуска
  соединений и потери введённого ответа; явные цвета ANSI остаются у программ.
- Новый вывод чатов и Logcat не перебивает чтение истории; есть явный
  возврат к новым сообщениям. Диагностика пульта выделяется и копируется с
  чувствительным буфером. Даты артефактов/истории используют общий пояс.
- Первый вход без GitHub открывает проекты. Уточнены версии SDK, возврат
  из раздела настроек и минимальные цели касания при плотном оформлении.

Кэши и прогресс из [dev.46](0.4.0-dev.46.md) сохранены. Форматы проектов,
профилей, задач, ключей и сессий не меняются. Реестр сохранённых функций и
физические сценарии — [единый интерфейс](../UI_REDESIGN.md).

Проверки на JVM/Actions не заменяют работу на телефоне: узкий экран,
клавиатура, крупный текст, восстановление процесса, смена темы в открытом
редакторе/терминале/оверлее и самосборка требуют физической приёмки.
