# 0.4.0-dev.46 — постоянные загрузки и живой прогресс

- Общие кэши Gradle, pip и npm для Linux/IDE/терминала/пульта; уже
  скачанный Gradle из прежнего Bionic home используется без переноса.
- Архивы SDK, ARM64-инструментов, JDK, Kotlin и языковых служб сохраняются
  после проверки суммы. Обрыв и повреждение не создают готовый компонент;
  параллельные установки одной суммы не скачивают его одновременно.
- Уже установленные ARM64-инструменты распознаются по закреплённым суммам.
  Пакеты Alpine и Bionic APT сохраняются; автоматическое вытеснение
  завершённых копий APK с ПК убрано, источники и версии изолированы.
- Живые этапы и индикаторы установок, счётчики шагов/пакетов/источников,
  проценты curl/Gradle и байты SFTP. Неизвестный объём не заменяется
  выдуманным процентом; вывод можно копировать, как в dev.45.
- Исправлен устаревший Gradle API регистрации задачи. Самосборка локальным
  clang не требует отсутствующий NDK для strip/symbol tables. Скрипт
  самосборки использует отдельный запуск Gradle и явно выбранный JDK;
  ненужное обнаружение Alpine JDK отключено только у этого проекта.
- Добавлен путь системной ICU Android для Bionic JDK; подтвердить загрузку
  библиотеки нужно на физическом телефоне.

Штатный `NO-SOURCE` сохранён. Предупреждения `minSdk 30 > targetSdk 28`,
экспериментального aapt2 override и отключённой оптимизации ресурсов
обусловлены рабочим режимом ARM64/Termux: изменение этих настроек ломает
совместимость. Внутренняя настройка Kotlin FUS остаётся ради запрета
телеметрии. Сообщения linkerconfig, HeapTagging и ограничения нативной
интеграции Gradle не скрываются и не заменяются фиктивными файлами.
Универсальный ARM64 NDK для других JNI-проектов остаётся отдельной задачей.

Самосборка dev.45 с телефона проверена перед вливанием PR #233: корректный
APK и подпись, DEX совпадает с CI. Для dev.46 ещё нужна физическая приёмка:
установка, первая и повторная сборка, восстановление из кэша без сети,
живой прогресс и повторная сборка после правки. Правила и пути —
[сохранение компонентов](../COMPONENT_CACHE.md).
