# 0.4.0-dev.40 — настройка окружения из API-чата

Тестовый APK из ветки `codex/automation-catalog`, PR #230, по поручению
22 ноября 2026. Публикация — в `apk_debug`; слияние в main не выполняется.
Точный коммит, SHA-256 и сертификат — в README/SHA256SUMS каталога сборки
и описании PR. Версия APK — 0.4.0-dev.40, versionCode 40040.

## Изменения после dev.39

- API-модель может проверить инструменты настоящим запуском, предложить
  установку/восстановление пакетов Alpine, Android SDK или команды
  исправления, затем получить результат и продолжить тот же ход.
- Подтверждение плана появляется прямо в чате. Для произвольной команды —
  красное окно и имя проекта; лицензию SDK принимает человек отдельным
  флажком. Модель не может одобрить действие сама.
- После установки основных инструментов выполняются живые пробы.
  Наличие Java больше не выдаётся за успешный запуск JVM. SDK проверяет
  запрошенные API/build-tools и запуск нативных инструментов; его путь
  обнаруживается следующими процессами автоматически, свой путь сохраняется.
- Bootstrap не требует работающих Git и Java. Используются прежние пауза,
  история и восстановление профилей; ошибка снимка останавливает команду.
  Отмена и таймаут относятся только к собственному запуску.
- Добавлены пробы JVM и mprotect с errno/размером страниц. Сообщение
  OpenJDK о PaX не выдаётся за доказательство причины или необходимости
  менять ядро. Обновление индекса apk тоже требует подтверждения плана.

## Где открыть и что проверить

1. «AI → Модели → Быстрый старт с ИИ» — выбрать существующий клон,
   API-ключ и модель. Для уже настроенного проекта открыть проектный чат.
2. Попросить: «Проверь и настрой окружение проекта, затем запусти проверки».
   Подтвердить предложенный план в приложении; вводить команды вручную
   не требуется. Общая команда дополнительно требует имени проекта.
3. В рабочем проекте → «Автоматизации» доступны те же пробы и планы.

нужна проверенная сборка под host или другой target.
