# 0.4.0-dev.42 — DNS для Android/Bionic JDK внутри Linux

23 ноября 2026. Исправление установщика JDK внутри DPmetaApp (без отдельного
Termux, root или SSH) после фактической ошибки `packages-cf.termux.dev`.

## Исправлено

- Android/Bionic библиотеки разрешают имена через DNS Resolver Android,
  используя системный UNIX-сокет `/dev/socket/dnsproxyd`. Прежде встроенный
  PRoot предоставлял только базовые устройства, поэтому `apt` из Termux
  не мог разрешить адрес репозитория, хотя сеть Alpine могла работать.
- PRoot предоставляет только `/dev/socket/dnsproxyd` и не открывает гостю
  остальные системные сокеты Android. Папка сокета создаётся в гостевом
  rootfs, данные установленного Linux сохраняются.
- Вместо прямого `apt-get` используется штатный Termux `pkg` (если он
  присутствует в официальном bootstrap): тот выбирает доступное зеркало
  пакетов. Для минимального bootstrap без `pkg` сохранён `apt-get`,
  но с проверкой `APT::Update::Error-Mode=any`, чтобы ошибка DNS не
  маскировалась последующим `Unable to locate package openjdk-21`.
- После успешной пробы компиляции/запуска класса в Linux регистрируются
  `java` и `javac` из Bionic JDK в `/root/tools/bin`. Пользовательские
  команды с такими именами не перезаписываются.

## Проверка на телефоне

1. Обновите APK, подписанный **тем же сертификатом**, что установленная
   версия. Если вы переподписывали предыдущую сборку другим ключом,
   сертификат из GitHub Actions может отличаться: это отдельное условие
   установки обновления, не ошибка DNS.
2. В «Настройки AI» → «Linux в приложении» → «Android SDK…» повторите
   установку. Стирать установленный Linux, проекты или данные приложения
   не требуется.
3. Дождитесь `DPAI_NATIVE_JDK_OK`; в **новом** терминале Linux проверьте
   `command -v java`, `java -version`, `javac -version`. Бинарные пути
   должны относиться к Bionic JDK, а не `/usr/bin/java` Alpine.
4. Дождитесь `DPAI_ANDROID_TOOLS_OK`, затем запустите профиль BUILD и
   проверьте Gradle и полученный APK. Сам успех CI не доказывает работу
   APK-компилятора на Redmi Note 13.

Если осталась ошибка `DPAI_NATIVE_JDK_PKG_FAILED` либо
`DPAI_NATIVE_JDK_APT_UPDATE_FAILED`, сохраните полный вывод: он поможет
различить недоступный сокет, отказ самой сети и проблему зеркала.
