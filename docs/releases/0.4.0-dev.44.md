# 0.4.0-dev.44 — получение PR с локальными изменениями

«Подтянуть последний PR» и «Собрать последний PR» больше не требуют
коммитить любые изменения и новые файлы. Совместимые изменения сохраняются,
включая staged/unstaged, и входят в последующую сборку. Повторный запуск
на уже полученном HEAD также работает с локальными правками.

Реальные пересечения показываются с именами файлов. Git защищает и
игнорируемые файлы от перезаписи; неразрешённые конфликты и свои коммиты
не сбрасываются. Автоматические commit/stash, force/reset и очистка не применяются.
Ключи, профили и остальные настройки проекта сохраняются.

Нужна физическая проверка на телефоне: получение последнего PR с местными
правками, затем самосборка DPmetaApp из установленной студии. Хостовый
стрессовый бюджет отслеживается отдельно в TODO; его порог не изменён.
