# 0.4.0-dev.43 — подготовка последнего PR и самосборка

- «Сборка» → «Собрать последний PR»: автоматически выбрать самый новый
  открытый PR origin, получить точный HEAD, обновить существующую привязку
  и запустить выбранный BUILD. Отдельно — «Подтянуть последний PR».
- Изменения Git, новые файлы, локальные коммиты и черновики не стираются.
  Привязка сохраняется до снятия durable-паузы, с восстановлением после сбоя.
- Шаблон DPmetaApp: release через локальные SDK/JDK и ARM64 sysroot,
  отладочная подпись и APK в артефактах. Переподпись прежним ключом — автором.
- Пробы Android/Bionic java/javac используют библиотеку совместимости JVM,
  как штатная сборка; заданный JAVA_HOME нативного JDK не теряет preload/sysroot.

APK из Actions предназначен для переподписи и установки автором.
Полный цикл самосборки из установленной release-студии ещё требует
проверки на телефоне; успешная облачная сборка её не заменяет.
