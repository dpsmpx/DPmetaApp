# Изменения правил

Здесь — изменения смысла правил `core/metrics/src/main/kotlin/com/dpsmpx/dpmeta/metrics/Rules.kt`
(CLAUDE.md, «Правила кода»; D-34): что, почему, ожидаемый эффект, как
проверить. Точки истории хранят версию правил; прежние не пересчитываются.

## Правила 2 — 4 ноября 2026 (этап 4)

- **Что.** Добавлены, прежние правила не изменены: PR ждёт автора — открыт и
  не черновик, шлюз готовности держит ждущий дольше 72 часов
  (`PR_WAITING_LIMIT`); время до вливания — медиана и P90 по последним
  влитым PR (`LEAD_TIME_PERCENTILE`); шлюз готовности этапа — шесть
  критериев по данным (D-64); доля удачных источников синхронизации — без
  ответов 404.
- **Почему.** Этап 4 (ТЗ, §8; D-58, D-64): стадии и шлюзы — метриками
  DPmetaApp; новые числа — из тех же ответов GitHub, без новых запросов (A-02).
- **Эффект.** В истории появляются `repo.pr.open.drafts`,
  `repo.pr.waiting_author`, `repo.pr.waiting_author.days`,
  `repo.pr.lead_time.median`, `repo.pr.lead_time.p90`, `repo.checks.last`,
  `repo.stage`, `repo.gate.passed`, `repo.gate.ready`, `app.sync.health`;
  неизвестное — без точки. Точки правил 1 не пересчитываются.
- **Как проверить.** `ReadinessTest` в `:tests:corpus` и снимки карточек
  `app/src/test/snapshots/`.

## Правила 1 — 1 ноября 2026 (этап 2)

- **Что.** Первая версия: «кто работает» — коммит в `main` за 6 часов,
  ветка или открытый PR, обновлённые за 24 часа (ТЗ, F-16; `DPmeta:M-08`);
  основная ветка — `main`; файла процесса нет (404) — снова спрашивается
  не раньше чем через 24 часа.
- **Почему.** Пороги ТЗ, F-16 — те же, что у DPmeta (`DPmeta:tools/activity.py`).
  Срок перепроверки 404 — по пробному прогону 1 ноября 2026: ответ 404 у
  GitHub без ETag, и без срока повторная синхронизация давала 85 % ответов
  304 вместо 90 % (ТЗ, A-02).
- **Эффект.** `repo.activity.state` и `eco.active_projects` появляются в
  истории; без веток и PR — «неизвестно», точки нет.
- **Как проверить.** `EcosystemSyncTest` в `:tests:corpus`: ветка за 24 часа
  — «работает»; проект без веток и PR — `Measure.Unknown`.
