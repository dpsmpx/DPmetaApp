# Очередь согласований

Расхождения, найденные мета-проходом, — по репозиториям, с точным местом
и предлагаемой правкой. Пункт, который можно сделать безопасно, сделан в
ветке `dpmeta/<цель>` (M-04) — его вливание в `main` остаётся отдельным
шагом автора или сессии того репозитория. Пункт в активном репозитории —
только записан: править его будет сессия самого репозитория по своим
правилам. Решения, а не правки, — в `docs/RISKS.md`.

Поля: **репозиторий**, **вид** (M-03), **риск**, **где**, **что не так**,
**предложение**, **состояние**. Места — на коммитах среза
`docs/reports/2026-10-05-xref.md`.
