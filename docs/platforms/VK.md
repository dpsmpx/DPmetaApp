# VK

Профиль `vk.com/dpsmpx` — **ACCESS = LIMITED** (аудит, §6): без входа
видно только «Dpsmpx Code» и аватар. Что сейчас публикуется, неизвестно.

## Модель

| Поле | Значение |
|---|---|
| Audience | широкая RU-аудитория: игроки, знакомые, начинающие разработчики |
| Purpose | короткие записи о главном: результат, релиз, веха |
| Primary content | RESULT, RELEASE, MILESTONE |
| Secondary content | PROJECT, PERSON |
| Length | короткая запись: 300–800 знаков + медиа; подробности — ссылкой на дневник |
| Visual format | 16:9 1280×720 или 1:1/4:5 для ленты; официальные размеры **не подтверждены** (`verified: false` в `export_specs.yaml`) |
| CTA | ссылка на видео или дневник |
| Posting rhythm | по вехам и релизам; не чаще дневника |
| Discoverability | лента друзей и подписчиков; сообщества; клипы |
| Retention mechanism | открытость профиля (сейчас закрыт для гостей) |
| Cross-platform role | короткая адаптация события для широкой аудитории |

## Открытые вопросы

- Личная страница или сообщество проекта? Личная закрыта для гостей —
  публикации там не видны не-друзьям. Решает автор (вместе с ОР-8).
- Размеры: официальной справки VK из сессии получить не удалось (поиск
  по `vk.com` недоступен, сторонние источники — 1920×768 обложка
  сообщества, 1590×400 и др.). До проверки по подсказкам загрузки VK —
  экспорт 16:9 1280×720 с безопасным центром.
