# Единый интерфейс студии

Основание — D-194: согласованные аудит и схемы экранов dev.46. Простой и
полный вид используют одни данные, команды и проверки полномочий.

## Реестр сохранения функций

| Область | Основное представление | Сохраняемые возможности |
|---|---|---|
| Рабочий проект | Код, чат, изменения; операции рядом | Все восемь прежних страниц и сохранённые имена маршрутов |
| Сборка и проверки | Запуск и результат; настройка раскрывается | Шаги, порядок, таймауты, параметры, окружение, нужные SDK/NDK, артефакты, разовый запуск без сохранения |
| Запуск | Рядом со сборкой | Своя команда/папка, сначала собрать, отменить только автозапуск, интерактивный терминал |
| Задачи | Лист задачи | Все 13 TaskAction, доступность по состоянию, зависимости, бюджет, ревью, архив |
| Сессии | Чат и меню | Все четыре SessionAction; остановка, пауза, отмена и handoff различимы |
| Чаты | Общий список с контекстом | API без проекта, проектные API и CLI, вложения, смена исполнителя, ограничения передачи |
| GitHub | Проект и прежние переходы | Просмотр без клона, документы, PR, ветки, issues, отзывы, публикация и журнал; отдельные аккаунты PAT/gh |
| Файлы | Код или файловый браузер | SAF, копия в Linux, общий накопитель по разрешению, SFTP, поиск/замена, вкладки, черновики |
| Редактор | Код и меню команд | LSP, дополнение, рефакторинг, предпросмотр, горячие клавиши, дзен и свои параметры файла |
| Инструменты | Настройки проекта/среды | Зависимости, автоматизации, DP-Verify, маршруты, локальные модели и Hugging Face |
| Терминал | Нативный терминал | PTY, SSH, tmux, клавиши, мышь, поиск, ANSI/truecolor, безопасный буфер и работа в фоне |
| Отладка | Результаты и прежние окна | DAP, точки останова, стек/переменные/выражения, Logcat и ADB |
| APK | Результат сборки | Скачивание, сведения, подпись, установка, запуск, экспорт, уровни ключей |
| Безопасность | Общие настройки | Вход, выдача секретов, аварийный отзыв, отдельный полный доступ чата и его отзыв при смене контекста |
| Восстановление | Общие настройки | Различимые копии приложения, контура и Alpine; состав, пароль, снимки и восстановление при перезапуске |
| Уведомления | Основное и расширенное | Тихие часы, дайджест, откладывание, правила, импорт/экспорт, проба и обязательные запросы |

## Контракт представления

Одна строка контекста проекта: имя, место выполнения, ветка выбранного дерева.
Полные пути раскрываются отдельно. Простой вид показывает основные действия;
«Все параметры» доступно в том же экране. Полный вид сохраняет прежние входы.
Нет автоматического повышения прав, запуска платной задачи или принятия
лицензии из-за смены представления.

Результат различает подготовку, ожидание, выполнение, успех, ошибку,
остановку и подтверждённую отмену. Известный процент относится к этапу,
неизвестный объём не превращается в выдуманный процент. Полный вывод
копируется с прежними лимитами и скрытием секретов. NO-SOURCE — штатный статус.

Тема одна: системная, белая, тёмная, чёрная. Акцент — фиксированный или
из обоев Android 12+, с запасным фиксированным на Android 11. Адаптивный
акцент не меняет нейтральную базу белой/чёрной темы. Редактор, оверлей и
нативные элементы используют выбранную тему; ANSI программы сохраняется.

## Приёмка

Проверить первый вход без GitHub, открытие локального/SSH/GitHub проекта,
сохранение вкладок и черновиков, разовый запуск изменённого профиля,
последний PR с локальными изменениями, переход из ошибки к строке,
возврат из настройки, отмену автозапуска без отмены сборки и все варианты
управления задачами. В простом и полном виде набор разрешённых действий
совпадает с прежним контрактом TaskScreens и SessionAction.

На телефоне: узкий/широкий экран, клавиатура, крупный шрифт, обе системные
темы с каждой выбранной темой, смена темы в открытом редакторе/терминале/
оверлее, возврат из уведомления и восстановление процесса. Изменения
оформления не перезапускают задачи или соединения.

## Реализовано в dev.47

Общая тема и простое/полное представление, рабочая область с листом операций,
единый возврат настроек, раскрываемые формы профилей/ключей/команд редактора,
копирование диагностики пульта и контролируемое следование новым сообщениям.
Смена темы не меняет полномочия и не запускает команды. Нативные контролы
сохраняют различимые состояния отключения, нажатия и клавиатурного фокуса. Прежние страницы
доступны через полный вид и меню операций; контроллеры действий не заменены.

Автоматически проверяются прежние восемь имён маршрутов, сохранённые ключи
оформления, контраст и приоритет выбранной темы. Реальная композиция пульта
и IDE сверяется с нативной палитрой и рисуется в восьми вариантах. Это не
доказательство прохождения всех интерактивных сценариев на Android:
физическая приёмка перечислена выше и остаётся в TODO.
