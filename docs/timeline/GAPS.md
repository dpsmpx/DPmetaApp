# Известные пробелы источников

Чего источники из реестра не покрывают — чтобы пробел не заполнялся
догадкой (CLAUDE.md, «Запрещено»). Пробел закрывается фактом с
источником; тогда строка удаляется в том же коммите.

| Пробел | Что известно | Факты |
|---|---|---|
| VoxelRPG до 2026-09-11 | первый коммит уже содержит 234 файла и 30 801 строку; по словам автора, код сгенерировал DeepSeek за 16 проходов; когда шла сессия DeepSeek и что в ней, источники не показывают — страница сессии из среды не открылась (N-0003) | F-0013, F-0014, F-0051 |
| Даты в истории git | даты коммитов записывает тот, кто коммитит; независимых меток времени для коммитов ранних проектов в реестре нет | F-0008, F-0009, F-0010 |
| Ранние публичные проекты | известны только первые коммиты пяти репозиториев; содержание, объём и связь с VoxelRPG не записаны | F-0008, F-0009, F-0010, F-0011, F-0012 |
| Остальные репозитории автора | в предмет не входят до решения (`docs/direction/DECISIONS.md`, «Отложено»); фактов о них нет | F-0002 |
| Закрытые источники | факты из закрытых репозиториев перепроверяет только владелец | F-0024 |
| Выпуск в Steam | факта о выпуске нет; наблюдения на 2026-10-04 | F-0032, F-0033, F-0034 |
