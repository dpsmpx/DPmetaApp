## Исполнение и права

Четыре источника адаптированы из существующих форматов. Команды пульта
разбираются в `app`; `core/formats` не зависит от автоматизаций, подсистема
не зависит от пульта. Мост устанавливает оболочка. Каталог не создаёт
второй worker, очередь, формат истории, менеджер пакетов или одобрения.
Нативный VerifyStep используется для метаданных шагов.

Целевая компиляция обнаружила обращение оболочки к внутреннему формату
пульта через его implementation-зависимость. Разбор перенесён внутрь
адаптера `app`: через мост возвращаются только общие описания. Направления
модулей и видимость зависимости не расширены.

Общий вызов проверяет id, актуальную ревизию, доступность, тип DIRECT,
имена/типы/варианты параметров и обязательное разрешение. Исполнитель
Android отдельно допускает только CHECK/BUILD и чтение диагностики.
OPEN_UI не превращается в выполнение по числовому уровню: остальные
инструменты открывают прежние экраны с подтверждением и терминалом.
Каталог относится к основному дереву; переход из дерева задачи явный.

Ревизия связана с полным профилем, сохранёнными вариантами, проектом и
target. Вызов использует прочитанный снимок, смена target отзывает сеанс;
native worker повторяет проверку target перед подготовкой. Черновики,
восстановление, занятость и долговечная пауза остаются штатными.
Отмена проверяется до подготовки, до start и в ожидании; остановка не
снимает паузу без подтверждения завершения. Перезапуск не повторяет start.

## Результат и данные модели

Исправлена найденная гонка: сравнения с предыдущим finished недостаточно
при раннем отказе подготовки и соседнем запуске. Worker передаёт id
именно своего подготовленного запуска; результат принимается только при
совпадении. Отдельные регрессии проверяют отсутствие подготовленного id,
чужой завершившийся запуск и собственный неудачный результат.

FAILED не заменяется успехом получения вывода. Доказательства содержат
реальный id, коды шагов, хеш и признак сокращения вывода; используются
прежние история и Redactor. Ошибка подготовки без собственного результата
остаётся отказом. Диагностика читает только окружение телефона и нужды
выбранного проекта, не запускает команды и явно сообщает commandsProbed=false.

API выдаёт безопасные варианты профиля, без исходных argv, env и настроек
SSH; полный источник участвует только в хеше ревизии. Листинг по умолчанию
показывает DIRECT. Страницы описаний сохраняют полную ревизию, сокращённый
результат остаётся целым JSON с хешем и явной отметкой. Новых сетевых
адресов, секретных хранилищ или платных запросов пакет не добавляет.
