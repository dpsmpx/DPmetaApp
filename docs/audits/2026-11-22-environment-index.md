# Дополнение: подтверждение обновления индекса пакетов

22 ноября 2026, после [обзора окружения](2026-11-22-api-environment.md).
Дополнительное чтение выявило действие UPDATE, ошибочно помеченное READ:
`apk update` записывает индексы окружения. По D-183 это изменение должно
получить подтверждение человека, хотя установленные пакеты не меняются.

UPDATE переведён на уровень 1 и снимок; план не добавляет переустановку
повреждённых пакетов к одному обновлению индекса. LIST_UPGRADES читает
готовую базу и остаётся уровнем 0. Ревизия описаний обновлена. Регрессия
проверяет, что без человеческого интерфейса UPDATE получает отказ, а
LIST_UPGRADES доступен; окончательные общие проверки — в PR #230.
