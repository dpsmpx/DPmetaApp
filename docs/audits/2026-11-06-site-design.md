# Аудит оформления сайта dpsmpx.com

- **Дата:** 6 ноября 2026
- **Опора:** `docs/WEB_DESIGN_APPROACHES_2026.md`
- **Объект:** статический сайт экосистемы (подсистема SocialMediaImage → `socialmediaimage/website/`, выгрузка на dpsmpx.com)
- **Источники кода:** `socialmediaimage/website/static/style.css`, `socialmediaimage/website/templates/base.html`, `socialmediaimage/assets/brand/tokens.json`, `socialmediaimage/docs/brand/VISUAL_SYSTEM.md`

Цель аудита — найти отклонения от актуальных подходов 2026 (performance-first, accessibility-first, mobile-first, осмысленный визуал) и зафиксировать приоритеты. Это не «сделать модно», а проверить фундамент и ясность.

---

## Краткий итог

Сайт уже стоит на крепком фундаменте авторской визуальной системы:

- Тёмная тема с семантическими цветами (человек / ИИ / проверено).
- IBM Plex Sans + Mono с `font-display: swap`.
- Skip-link, `:focus-visible`, семантическая разметка, адаптив под 390 px.
- Ограничение max-width 860 px и простая иерархия — сознательный минимализм «инженерной мастерской», а не попытка угнаться за bento/glass.

Серьёзных блокирующих проблем по performance и a11y не видно. Есть точечные улучшения, которые стоит закрыть до следующего крупного обновления контента/страниц.

## Находки

### HIGH (влияют на всех пользователей / соответствие WCAG / Core Web Vitals)

| ID | Проблема | Почему важно | Где | Рекомендация |
|----|----------|--------------|-----|--------------|
| S-01 | Нет `prefers-reduced-motion` | Пользователи с вестибулярными нарушениями и те, кто отключил анимации в ОС, получают движение без согласия. В 2026 это базовый столп accessibility-first. | `style.css` (нет медиазапроса) | Добавить `@media (prefers-reduced-motion: reduce)` и отключать/упрощать любые transition/animation (даже если сейчас их мало). |
| S-02 | Возможный layout shift у изображений | `img { max-width: 100%; height: auto; }` без явных `width`/`height` или `aspect-ratio` в разметке может давать CLS при загрузке. | CSS + шаблоны страниц | В генерируемых `<img>` всегда указывать размеры или `aspect-ratio`. Проверить LCP-изображения (hero/cover). |

### MEDIUM (заметное отклонение от лучших практик 2026)

| ID | Проблема | Почему важно | Где | Рекомендация |
|----|----------|--------------|-----|--------------|
| S-03 | Зоны нажатия навигации | `nav a { padding: 8px 0; }` — высота цели касания может быть меньше 44×44 px (WCAG 2.5.8). На телефоне сложнее попасть. | `.site-header nav a` | Увеличить вертикальный padding до ≥ 12–14 px или сделать min-height 44 px с выравниванием. |
| S-04 | Только тёмная тема | Токены и CSS заточены под dark. Светлая тема отсутствует. Для части пользователей (яркий свет, некоторые нарушения зрения) это снижает комфорт. | Вся тема | Не срочно: бренд сознательно тёмный. Если добавлять — parallel light tokens + `color-scheme` / media. Пока можно оставить как deliberate choice. |
| S-05 | Нет явных micro-interactions на интерактивных элементах | Hover есть, но нет лёгкой обратной связи на press/focus beyond outline. В 2026 микро-взаимодействия (150–300 мс) помогают ощущению отзывчивости. | CSS | Добавить `transition` на color/border у ссылок и кнопок (с уважением reduced-motion). Не обязательно «вау». |

### LOW / INFO

| ID | Замечание | Комментарий |
|----|-----------|-------------|
| S-06 | Несколько файлов шрифтов | 4 начертания Sans + Mono. С `font-display: swap` это приемлемо, но увеличивает число запросов. Можно рассмотреть subset или variable font, если появятся новые веса. |
| S-07 | Классическая одноколоночная ширина 860 px | Не bento, не асимметрия. Для личного/документального сайта это плюс (читаемость, спокойствие). Соответствует VISUAL_SYSTEM («пустое пространство — часть композиции»). Менять не нужно. |
| S-08 | Нет kinetic typography / glass / 3D | Сознательно. Документ подходов прямо говорит: применять только если усиливает понимание. Здесь не усиливает. |
| S-09 | Контраст | Токены заявлены под AA (paper на ink ≥ 4.5). Автопроверка в пайплайне есть. При изменении токенов — обязательно перепроверять. |

## Что уже хорошо (не трогать без причины)

- **Семантика и a11y-база:** skip-link, `tabindex="-1"` на main, `aria-label` на nav, `:focus-visible`.
- **Типографика:** IBM Plex + чёткая иерархия + mono для данных.
- **Цвет как смысл:** human / ai / verified — это сильная сторона, а не декорация.
- **Mobile:** медиазапрос 600 px, уменьшение размеров, перестройка таблиц/фигур.
- **Производительность-база:** `font-display: swap`, нет тяжёлых библиотек, SVG-фигуры без скриптов где возможно.
- **Визуальная система:** документ `VISUAL_SYSTEM.md` и токены — живой источник истины. Это редкость и преимущество.

## Приоритет работ

1. **S-01** (reduced-motion) — быстро, без визуального риска.
2. **S-02** (размеры изображений) — проверить генератор страниц и LCP.
3. **S-03** (touch targets навигации) — мелкий CSS-фикс.
4. Остальное — по желанию / при следующем редизайне секций.
