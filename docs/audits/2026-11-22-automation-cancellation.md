# Отмена автоматизации: дополнение к проверке

22 ноября 2026, после [основного прохода](2026-11-22-automation-catalog.md).
Срез `a88a4415` прошёл affected, dpai full и корневой full --strict 24/24
(453 задачи, 853,9 с), но дополнительное чтение выявило гонку сигнала остановки.

После завершения или раннего отказа своего worker его общий слот уже может
занять соседний профиль. Поздний `model.stopManualProfile()` из ожидающего
API-вызова тогда выставляет глобальный manualStop соседу. Корреляция
результата по id эту отдельную гонку не устраняет.

Глобальный сигнал удалён из API-пути. Worker уже слушает Cancel своего
вызова до подготовки/start и при ожидании. Таймаут получает отдельный
локальный Cancel, чтобы остановить только этот профиль и вернуть ошибку
модели, сохранив возможность продолжить чат. Пауза снимается прежним
механизмом только после подтверждения остановки. Кнопка ручной остановки
самого профиля не меняется.

Сама сессия повторно просмотрела путь подготовки, ожидания, onFinished
и восстановления: другой worker не получает ссылку на эти флаги.
Повторные проверки итоговой головы — в PR #230; приёмка отмены на устройстве
дополнена в TODO.md. Нового планировщика, типа отмены или формата не добавлено.
