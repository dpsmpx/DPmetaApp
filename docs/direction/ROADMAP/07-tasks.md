# Этап 7 — Задачи и планировщик

Состояние: выполнен (6 октября 2026).

## Цель

Детерминированный планировщик с зависимостями, приоритетами,
справедливостью и учётом ресурсов (D-22; ТЗ, §17, §18, §21, §22, §83–§86,
§120, §130).

## Объём

- Модель задачи (ТЗ, §7), доска состояний (ТЗ, §41), DAG (ТЗ, §42),
  обнаружение циклов `DEPENDENCY_CYCLE` (ТЗ, §120).
- Приоритеты, старение, справедливость, квоты; ручной приоритет выше
  вычисленного, если политика разрешает.
- Политики: операции, одобрение, повтор, параллельность, контекст,
  проверка, тайм-ауты, ресурсы (ТЗ, §20).
- Повтор по классу (D-05), защита от петель `LOOP_DETECTED` и livelock
  (ТЗ, §22, §121).

      голодания нет при старении: `TasksTest`.
- [x] Цикл зависимостей обнаруживается; петля повторов останавливается:
      `TasksTest`.
