# Этап 6 — Сессии

Состояние: —.

## Цель

Реестр и жизненный цикл сессий по формальному автомату (D-11,
`docs/SESSION_MODEL.md`; ТЗ, §8, §15, §129).

## Объём

- Реестр сессий, связь задача + аккаунт + target + worktree + сессия
  (ТЗ, §29).
- Heartbeat со свежестью `FRESH` → `AGING` → `STALE` → `UNKNOWN` →
  `DEAD` по нескольким порогам (ТЗ, §15).
- Поток событий сессии, история, пауза, продолжение, остановка, повтор.

## Критерии выхода

- [ ] 20+ одновременных синтетических сессий проходят тесты (ТЗ, §139,
      Phase 6).
- [ ] Пропуск heartbeat не превращается сразу в «упала».
- [ ] Повтор и продолжение не создают второй идентичной сессии
      (идемпотентность, ТЗ, §5.4).
