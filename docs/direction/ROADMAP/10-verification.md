# Этап 10 — Проверка

Состояние: —.

## Цель

Завершённая Claude задача проверяется автоматически до `VERIFIED`
(D-23; ТЗ, §5.2, §32, §33, §139, Phase 10).

## Объём

- Профили `FAST`, `NORMAL`, `FULL` с критериями достаточности (ТЗ, §33).
- Уровни `static`, `affected`, `full`, `doctor`, `plan`, `report`,
  `baseline` — для проектов, над которыми работает Claude; адаптер к
  внешнему DP-Verify (D-16).
- Доказательства: команда, код выхода, хеш вывода, время, коммит.

## Критерии выхода

- [ ] Задача, о которой Claude сказал «готово», автоматически
      проверяется до `VERIFIED` (ТЗ, §139, Phase 10).
- [ ] Без проверки — `COMPLETION_UNVERIFIED`, а не `DONE`.
