# Этап 5 — Выпуск

Состояние: —

До этого этапа релизная сборка не публикуется (`CLAUDE.md`,
«Чего не делать»).

## Работы

1. **Название и `applicationId`** (D-01, отложенное).
2. **Подпись и R8**: ключ подписи вне репозитория (`check_secrets.py`
   запрещает файлы ключей), правила R8, проверка, что R8 не ломает
   ядро (корпус на релизной сборке).
3. **Лицензии в приложении**: экран «О программе» с уведомлениями
   компонентов из `docs/legal/THIRD_PARTY_MATRIX.md` (Apache-2.0
   NOTICE, MPL-2.0 Xray — где взять исходники).
4. **minSdk** — пересмотр (отложенное).
5. **Каналы распространения** (отложенное): Google Play, RuStore, APK;
   правовой фон на дату решения (`docs/research/RUSSIA_NETWORK_RESTRICTIONS.md`).
6. **Лицензия и открытость репозитория DPpass** (отложенное).
7. **Обзор безопасности**: модель угроз (`docs/SECURITY_MODEL.md`)
   пройдена по пунктам, остаточные риски записаны.
8. **Воспроизводимость сборки** — насколько позволяет Go-ядро.

## Критерии выхода

- [ ] Подписанная релизная сборка проходит hostcheck в полном режиме и
      проверку на устройствах из этапа 3.
- [ ] Все отложенные решения, помеченные «перед выпуском», приняты.
