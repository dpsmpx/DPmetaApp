# Уведомления разработки

В настройках пульта блок «Уведомления разработки» управляет движком
правил D-140/D-142. Обычные сообщения ИИ проходят те же правила,
тихие часы и приватность. Запросы с решениями, сообщения SECURITY и
APPROVAL сохраняют обязательный показ через собственные каналы.

Тихие часы задаются временем и днями начала ночи. Пустой выбор дней —
каждый день. Например, понедельник 22:30–06:00 продолжается во вторник
до 06:00. Используется общий часовой пояс приложения. Правило с
`quiet = false` обходит тишину; разрешение, звук и запрет беспокойства
по-прежнему определяет Android. Кнопка каналов открывает его настройки.

Приватность скрывает проекты и текст на заблокированном экране.
При её включении прежние карточки пульта и обычных сообщений ИИ
удаляются. Обязательные запросы и уведомления работающих служб
сохраняются; сообщения безопасности всегда приватны.

«Правила и проба по ленте…» позволяет включать правила и выбирать
«уведомить», «только лента» или «промолчать». Условия, порядок и новые
правила правятся в TOML; порядок важен — действует первое подходящее.
Быстрый переключатель сохраняет все условия, но канонизирует текст;
расширенная правка сохраняет комментарии и форматирование.

Импорт UTF-8 до 65536 знаков сначала загружает черновик. Проверка
происходит до записи; неверный файл сохраняет прежние рабочие правила.
Экспорт пишет текущие правила в выбранный файл. Пороги — целые Int64.
Выражения используют RE2 (D-141), до 200 знаков: без обратных ссылок
и lookaround. Неподдержанное отклоняется до записи; Java backtracking
не используется. Поля формата описаны в `config/alerts.toml`; типы и числовые поля видны
в расширенном редакторе. Контентные события site/social в студию не входят.

Проба за семь дней использует загруженную ленту и локальную историю
кандидатов сообщений ИИ и ничего
не отправляет. Она показывает решения движка, а не гарантирует доставку
Android. Дайджест по расписанию ещё в плане; активное правило `digest`
отклоняется при сохранении, чтобы не обещать недоступную доставку.

«По умолчанию» загружает шаблон для просмотра; только «Сохранить»
удаляет личное наложение. При повреждении настройки приложение
не включает правила APK молча. Личная настройка хранится через
DocumentStore (`dpmeta.alert-rules` v2), отдельно от шаблонов APK.
Прежний v1 читается без перезаписи: стандартные правила ИИ дополняются
в памяти и видны в редакторе до сохранения. В v2 отсутствие правила ИИ
означает «только лента».

История ИИ ограничена последними 200 записями за семь дней; текст
сокращён до 2048 знаков, секреты редактируются до записи. Повторы
обновляют запись. Решение silent скрывает её из ленты, сохраняя для
пробы правил. Касание записи открывает ИИ; проект не угадывается.

(Robolectric API 36: обязательный показ, тихие часы, гонка приватности);
