# Зависимости проекта в API-чате

DP_AI_Orcestrator:D-217, этап 1 DPmetaApp:D-172. Используются те же
инструменты и профили, что у панели «Зависимости» в IDE. В проектном
чате можно попросить модель проанализировать зависимости, предложить
закрепление версий и после этого проверить проект.

## Вызов

Через общий каталог `list_automations` / `describe_automation`:

- `dependencies.project`: manager — gradle/python/conan; mode — report,
  pin или restore. Restore доступен только для Python. Python — буквальный
  путь на выбранном target; для pip следует выбрать интерпретатор venv
  проекта. androidSdk=yes подключает SDK приложения для локального Gradle;
  удалённый target использует свои инструменты.
- `dependencies.report`: manager выбирает только один из трёх штатных
  отчётов. Для следующих страниц нужны nextOffset и sha256 из ответа.
  Смещение относится к тексту после редактирования известных секретов.
  При изменении хеша требуется начать чтение заново.

План выполнения подтверждает человек прямо в приложении. Видны target,
путь дерева и последствия режима. Модель не может сама одобрить план.
Сначала нужно сохранить или отменить черновики; занятый контур не
обходится. Профиль использует прежнюю историю и паузу до завершения.
На SSH-target нужны Python и выбранный менеджер; на телефоне — Linux
приложения. Ключ API модели этим инструментам не передаётся.

Отчёт сохранён в .dp-ide/dependencies, может быть старым и не доказывает
готовность сборки. API возвращает freshnessVerified=false. Обычные
файловые инструменты не получают доступа к остальной служебной папке.

## Что изменяется

Даже report может выполнять сценарии проекта, загружать зависимости
и создавать отчёт. Pin использует штатное закрепление Gradle, снимок
проверенного Python venv или conan.lock; это не универсальная фиксация
любого CMake-проекта. Восстановление pip выполняется только в venv.
Подробные предупреждения прежней панели сохраняются в окне плана.

После pin/restore нужно просмотреть Git diff и запустить проверки.
При отказе менеджера часть файлов могла измениться; код ошибки не
превращается в успех. Снимок пакетов Alpine и полная копия файлов проекта
для этой операции не создаются. Выборы сохранённых профилей не меняются.
