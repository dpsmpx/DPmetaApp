## Что нового после опубликованной dev.39

- Настройка окружения из проектного API-чата: живые пробы инструментов,
  установка и восстановление пакетов Alpine, Android SDK и команды исправления.
  Модель получает фактический результат и продолжает тот же ход.
- Подтверждение плана прямо в приложении. Для общей команды — красное окно
  и имя проекта; лицензию SDK принимает человек. Самоодобрения у модели нет.
- После установки основных инструментов проверяется их настоящий запуск.
  Успешный apk с отказом JVM не выдаётся за готовое окружение. SDK проверяет
  запрошенные версии и нативные инструменты; ANDROID_HOME обнаруживается автоматически.
- Bootstrap без исправных Git/Java, снимки и история под прежней паузой проекта,
  собственные отмена и таймаут без остановки соседнего запуска.
- Пробы java_debug и memory для ошибки mprotect: errno и размер страниц,
  без неподтверждённых советов менять ядро или применять paxctl.
  Обновление индекса apk тоже требует подтверждения плана.

## Где открыть

«AI → Модели → Быстрый старт с ИИ» — выбрать клон, ключ и модель.
В проектном чате попросите: «Проверь и настрой окружение проекта, затем запусти проверки».
Подтвердите предложенный план в приложении. Вводить команды вручную не требуется;
для произвольной команды дополнительно вводится имя проекта.
Рабочий проект → «Автоматизации» — те же пробы и планы.

## Проверки и приёмка

full --strict на указанном коммите: 24/24, общая сборка/тесты/Lint и 37 проверок APK.
Замеры выполнены отдельным последовательным шагом с прежними порогами.
Код функций e518cb14 также прошёл affected и dpai full; 21 новый регрессионный тест без пропусков.
ZIP, DEX, версия, метка коммита и подпись APK проверены перед загрузкой.

Причина отказа mprotect на телефоне ещё не установлена — нужны новые пробы
java_debug и memory. Эта сборка не объявляет её исправленной без проверки.
Официальные Linux aapt2/NDK не становятся совместимыми с arm64 от загрузки:
нужна проверенная сборка под host или другой target.
Телефон и SSH-target требуют приёмки: диалог и продолжение чата, лицензия/отказ,
отмена и соседние запуски, фон/перезапуск, настоящие пакеты и SDK.
Proot не является песочницей; снимок пакетов не является полной копией файлов
произвольной команды. Хостовые проверки не заменяют приёмку телефона.
Остальные триггеры/CLI/композиция Automation Engine — в плане.
