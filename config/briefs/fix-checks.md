Поручение пользователя: проект {{project}}, репозиторий {{repo}}.

Разбери красные проверки PR #{{pr}}. Найди, что именно падает (проверки
репозитория по его `CLAUDE.md`, раздел «Проверки» описания PR), и докажи
причину: упавшая команда сперва разбирается по коду возврата и окружению.

Поломка этого PR — почини в его ветке и прогони проверки снова. Поломка
не от этого PR — не чини её здесь: запиши в описание PR и `TODO.md`.
Итог проверок — в описание PR. Вливать без слова автора нельзя.
